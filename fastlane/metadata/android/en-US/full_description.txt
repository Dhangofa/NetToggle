NetToggle is a lightweight Android Quick Settings tile for switching cellular network modes.

Supported network modes:

- 5G Only
- 4G Only
- Preferred 5G
- Preferred 4G

Execution methods:

- Root
- Shizuku

Root or Shizuku is required because standard Android apps cannot directly change preferred network modes.

The app is designed to stay lightweight by using cached tile state, async command execution, cached icons, and no background polling.
- Note : Samsung One UI not supported as of now.
